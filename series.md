# Qdrant blog series

Each post in the series completes the sentence "Qdrant is a ___ engine." The last post, "Putting it all together," ties the parts into "Qdrant is a Search Engine."

## Posts

1. **Storage Engine**: first draft written. Dimensions, distance, quantization, payload types, and strict mode.
2. **Distribution Engine**: collections, segments, sharding, and replication.
3. **Semantic Engine**: how words become vectors that carry meaning.
4. **Compression Engine**: quantization and TurboQuant trade-offs.
5. **Relevance Engine**: scoring, fusion, and reranking.
6. **Vector Engine**: dense, sparse, and multivector overview.
7. **Faceting Engine**: counts and grouped results from payload fields.
8. **Retrieval Engine**: feeding search results into RAG pipelines.
9. **Recommendation Engine**: recommend and discover queries from examples.
10. **Hybrid Engine**: dense and sparse vectors working together.
11. **Filter Engine**: payload indexes, filter performance, and strict mode.
12. **Ranking Engine**: fusion and reranking results.
13. **Cloud Engine**: running managed Qdrant clusters, including built-in inference.
14. **Deployment Engine**: the operating models: Managed Cloud, Hybrid Cloud, Private Cloud, and open source. Serverless to be added once it is confirmed.
15. **Operations Engine**: snapshots, monitoring, upgrades, and access control.
16. **Multitenant Engine**: keeping many users' data separate in one collection or cluster.
17. **Search Engine**: closing post, putting it all together.

Order after post 3 is not fixed yet.
